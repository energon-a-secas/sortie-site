# CLAUDE.md: Sortie

Sortie: mech cockpit console; a device-ID gate boots a 22-slot component matrix out of the core mark, a 12x12 glyph forge builds your own parts (36 hex chars each, so a whole custom library fits in a share-link hash), and four burst modes repaint every token + shift the frame's stats. Visitor-set accent with a luminance-derived foreground, three matrix layouts, canvas poster export, idle attract loop (sortie.neorgon.com)

**Live:** sortie.neorgon.com · **Port:** 8863

## Run

```bash
make serve
```

Then open http://localhost:8863. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Data

- `localStorage['sortie-state']`

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
